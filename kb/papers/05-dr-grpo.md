# 05 Dr. GRPO：R1-Zero 式训练的批判性分析

> 论文：Understanding R1-Zero-Like Training: A Critical Perspective
> 作者：Zichen Liu（第一作者、项目负责人）、Changyu Chen、Wenjun Li、Penghui Qi、Tianyu Pang、Chao Du、Wee Sun Lee、Min Lin（Sea AI Lab、新加坡国立大学、新加坡管理大学）
> arXiv：[2503.20783](https://arxiv.org/abs/2503.20783)，v1 2025-03-26（本文核对 v2，COLM 2025 版）
> 相关章节：[training/03 GRPO 及其变体](../tracks/training/03-grpo-family/README.md#3-dr-grpo去掉两处归一化)
> 相关方向：training

论文分两部分：第 2 节分析基座模型，第 3 节分析 RL 算法。面试问得最多的是第 3 节提出的 Dr. GRPO（GRPO Done Right），但第 2 节关于“基座本来就会”的结论同样重要，常被用来追问“RL 到底学到了什么”。

## 1 解决什么问题

DeepSeek-R1-Zero 之后，大量开源复现在 Qwen2.5 基座上直接做 RL，并把“训练中回答越来越长”和“aha moment”解读为 RL 让模型学会了长推理和反思。论文质疑两点：

- **基座的作用被低估**。Qwen2.5 等基座在 RL 之前可能已经具备解题和自我反思能力，RL 的“巨大提升”有一部分是在修复模板带来的损害。
- **长度增长有一部分来自 GRPO 目标的偏差**，而不全是能力的涌现。尤其是错误回答越来越长。

## 2 方法

### 2.1 基座分析（第 2 节）

- **模板决定基座是在“答题”还是在“续写”**（2.1 节）。对比 R1 模板、Qwen-Math 模板和不用模板。Llama 和 DeepSeek 系列用 R1 模板后更会答题；Qwen2.5 系列不用模板时答题率最高。所有测试的基座 pass@8 都不低，说明都有探索能力，可以做 RL；如果一条正确轨迹都采不到，RL 没有奖励信号，也就无从改进。
- **Qwen2.5-Math 不用模板反而最好**（2.2 节、表 1），比传统 4-shot 提示平均提升约 60%。作者推测它在预训练时就用过拼接起来的问答文本，基座已经“像 SFT 过的模型”，用它复现 R1-Zero 要更小心。
- **aha moment 在基座里已经存在**（2.3 节）。作者自己部署 DeepSeek-V3-Base 测试，发现它也会产生相当多的自我反思（附录图 13 有“Aha”“wait”的例子）。R1-Zero 的反思行为更多，但反思和更高的准确率并不正相关（附录 F）。反思的统计用关键词检测和 LLM 判断交叉验证（附录 D）。

### 2.2 GRPO 的两个偏差（3.1 节）

论文的 GRPO 目标（式 3）按 β = 0 写，即不带 KL。作者的理由：用规则 Verifier 做奖励时不存在奖励模型的分布偏移问题，KL 可以去掉，还省掉参考模型的显存和计算。

```
J_GRPO = E[q~p_Q, {o_i}~π_θold(·|q)]
    (1/G) Σ_i (1/|o_i|) Σ_t min( ρ_{i,t} Â_{i,t} , clip(ρ_{i,t}, 1−ε, 1+ε) Â_{i,t} )
Â_{i,t} = ( R(q,o_i) − mean({R(q,o_1) … R(q,o_G)}) ) / std({R(q,o_1) … R(q,o_G)})
```

图 4 把它写成“无偏优势被重新加权”：

```
GRPO 实际起作用的优势  a_{i,t} = Ã_{i,t} / ( std(R) · |o_i| )
无偏优势              Ã_{i,t} = R(q, o_i) − mean(R)
```

两个分母各带来一种偏差：

| 偏差 | 来源 | 效果 |
|---|---|---|
| 回答级长度偏差 | 除以 `|o_i|` | 优势为正（答对）时，越短的回答每个 token 更新越大，策略偏好简短的正确回答；优势为负（答错）时，越长的回答每个 token 受罚越小，策略偏好冗长的错误回答 |
| 问题级难度偏差 | 除以 `std(R)` | std 小的题（太容易或太难，奖励几乎全是 1 或全是 0）在更新中权重被放大 |

关于 std 归一化，论文补充：优势归一化是 RL 常用技巧，但通常在整个 batch 上做；按问题归一化会让不同问题在目标里权重不同，这才是偏差。

**开源 PPO 实现也有长度偏差**（表 2、代码清单 1）。trl、OpenRLHF、verl 等实现都按回答长度归一化 loss，和 PPO 目标（式 2，对 token 直接求和）不一致；这个不一致在 GRPO 发表前就存在。作者推测它来自预训练：预训练把 token 打包进固定长度上下文，按上下文长度求平均有助于数值稳定；但 RL 阶段回答长度不是常数，同样的写法就引入了偏差。清单 1 列了两种有偏写法（摘自论文，不可单独运行）：

```python no-run
def masked_mean(tensor, mask, dim):
    return (tensor * mask).sum(axis=dim) / mask.sum(axis=dim)      # 有偏
    # 改为：return (tensor * mask).sum(axis=-1) / MAX_TOKENS       # Dr. GRPO

loss_variant1 = masked_mean(ppo_loss, response_mask, dim=-1).mean()   # 按每条回答长度归一化（如 OpenRLHF）
loss_variant2 = masked_mean(ppo_loss, response_mask, dim=None).mean() # 按整批 token 数归一化（如 trl、verl）
```

`MAX_TOKENS` 是整个训练中不变的全局常数，即最大生成长度。论文说其他常数也可以，只是梯度范数不同。

### 2.3 Dr. GRPO（3.2 节）

做法只有两步：去掉 `1/|o_i|` 和 `std(R)`；实现上把 `masked_mean` 的分母换成常数。附录 A 推导出去掉后的梯度（式 6）：

```
∇_θ J = E[q, {o_i}] (1/G) Σ_i Σ_t ∇_θ log π_θ(o_{i,t} | q, o_{i,<t}) · Ã_{i,t}
Ã_{i,t} = R(q, o_i) − mean({R(q,o_1) … R(q,o_G)})
```

论文的说法是：这样就恢复了 PPO 目标，优势用蒙特卡洛回报加一个无偏基线来估计。基线取组内平均奖励，它不依赖当前 token，所以不改变梯度的期望，只降低方差（附录 A 给出了证明）。

**实验设置**（3.2 节、附录 G 表 6）：Oat 框架，Qwen2.5-1.5B 基座加 R1 模板，MATH 训练集，奖励用 Math-Verify 判断最终答案，对为 1、错为 0。最大回答长度 3000，温度 1.0，每题 8 个回答，学习率恒定 1e-6，KL 系数为 0，clip 参数 0.2，每批数据只做 1 个内层更新。8 张 A100 约一天跑完。

## 3 关键实验结论

- **Dr. GRPO 抑制了长度的无序增长**（图 5）。两种算法训练中回答长度都随奖励上升；但奖励增长放缓后，GRPO 的回答还在继续变长，Dr. GRPO 没有。评测时 Dr. GRPO 错误回答的长度明显更短，论文认为无偏优化器也缓解了过度思考。
- **两个偏差的消融**（附录 C、图 8）。去掉长度归一化的变体和 Dr. GRPO 一样产生更短的回答，说明长度偏差对回答长度影响更大；只去掉任意一项的变体，训练奖励和评测准确率都比原始 GRPO 好。附录图 9 用 3 次独立运行检验了结果的稳定性。
- **模板和题目覆盖的相互作用**（3.3 节、图 6、表 3）。模板决定初始策略的水平，但在合适的题目集上，RL 能把各种模板下的策略提升到相近水平。用 R1 模板（和 Qwen2.5-Math 不匹配）时，提升主要靠 RL，需要题目覆盖面广；用 Qwen-Math 模板时，在更简单、分布外的 GSM-8K 上训练，反而让更难题目上的准确率接近翻倍。论文的解读：RL 在这里主要是强化有用的推理行为，而不是注入新知识；模板不匹配时会先破坏能力，再由 RL 重建，所以对纯 RL 带来的提升要更保守地下结论。
- **领域预训练抬高 RL 上限**（3.4 节、图 7 左）。原始 Llama-3.2-3B 做 RL 提升很小；在数学语料（FineMath）上继续预训练，再用拼接的问答文本（NuminaMath-1.5）继续预训练后，RL 效果明显更好。
- **“长度和准确率一起涨”可能是假象**（图 7 右）。在 Llama 上 GRPO 同样出现长度和准确率双升，容易被误读为长 CoT 涌现；Dr. GRPO 下长度不再那样增长。

## 4 局限与后续工作

论文没有单独的局限一节。阅读时需要注意的边界：

- 实验主要在 1.5B 到 7B 的模型和数学任务上，最大回答长度 3000，比 R1-Zero 和 DAPO 的长 CoT 设置短得多。
- 去掉 std 后，优势的尺度随奖励的尺度变化，奖励设计变了学习率可能也要跟着调；论文没有展开讨论。
- “Qwen2.5 预训练时用过拼接的问答文本”是作者的推测，论文用表 1 的现象支持，没有直接证据。

和其他工作的关系：

- [04 DAPO](04-dapo.md) 同样处理长度问题，但做法不同：DAPO 用整组总 token 数做分母，并保留 std 归一化；Dr. GRPO 用固定常数做分母，并去掉 std。注意 Dr. GRPO 把“按整批 token 数归一化”（loss_variant2）也列为有偏写法，因为每批的 token 总数不是常数。
- [06 GSPO](06-gspo.md) 从另一个角度改 GRPO：比率的单位，而不是归一化方式。
- Agent 多轮训练里，按每条轨迹求 masked mean 再平均同样会带上长度偏差，见 [training/04 第 3 节](../tracks/training/04-agentic-rl/README.md#3-工具返回的-loss-mask)。

## 5 面试常见追问

1. 为什么 `1/|o_i|` 会让错误回答变长？→ 错误回答的优势为负，每个 token 的惩罚是优势除以长度。同样是错，越长的回答每个 token 罚得越轻，策略就倾向于在答错时写长。答对时反过来，越短的回答每个 token 奖励越大。
2. 为什么除以 std 是偏差？→ std 是按每个问题算的。几乎全对或几乎全错的题 std 很小，除以它后这些题的权重被放大。batch 级归一化对所有样本乘同一个数，不改变相对权重；问题级归一化让不同问题权重不同。
3. Dr. GRPO 的分母为什么用常数而不是总 token 数？→ 常数分母让每个 token 的权重完全固定，不依赖它所在回答和所在 batch 的长度，梯度恢复为标准的策略梯度。按 batch 总 token 数归一化时，分母随 batch 变化，论文把这也列为有偏写法。常数取多少只影响梯度尺度，相当于调学习率。
4. 训练中回答变长就说明模型学会了长推理吗？→ 不一定。论文显示 GRPO 在奖励不再上升后仍让回答变长，尤其是错误回答，这部分来自长度偏差；Llama 上的长度和准确率双升，换成 Dr. GRPO 后长度不再那样涨。判断时要分开看正确和错误回答的长度，并对照验证集准确率。
5. aha moment 是 RL 带来的吗？→ 论文发现包括 DeepSeek-V3-Base 在内的基座已经会产生反思类表达；R1-Zero 的反思更多，但反思频率和准确率不正相关。所以不能把“出现 wait”直接当作 RL 学到新能力的证据。
6. 为什么不用 KL？→ 规则 Verifier 不存在奖励模型的分布偏移问题，不需要 KL 把策略拉在参考模型附近；去掉 KL 还省掉参考模型的显存和计算。DAPO 也去掉了 KL，理由是长 CoT 训练中模型本来就要大幅偏离初始模型。
