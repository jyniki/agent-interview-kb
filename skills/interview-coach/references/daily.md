# 每日任务

用户说“今天学什么”，或定时任务触发时，走这个流程。

## 1 取任务

```bash
python3 <skill目录>/scripts/coach.py today --json
```

返回内容：

- `new`：今天要新学的章节，带学习方式（`mode`）和原文路径。
- `reviews`：今天到期的复习题。`priority` 为真的是真实面试题，排在最前。
- `review_overflow`：超出今天时间、没列出来的到期题数。
- `coding`：今天的一道手撕题（复习日没有）。
- `mock`：复习日的模拟面试建议。
- `notes`：距面试天数、落后提示等。

## 2 整理成今日清单

按下面的格式给用户，控制在一屏以内：

```
今天（12-03 周三）约 150 分钟
1. 新学：GRPO 及其变体，约 150 分钟。弱项：先看推导，再合书作答。
2. 复习 6 题，约 30 分钟（2 道上次 0 分的放最前）。
3. 手撕：GRPO 的组内优势和 token 级 loss。
距面试 48 天。
```

然后问用户先做哪一项。不要一次把所有题目都抛出来。

**定时任务触发、用户不在场时**：只输出今日清单，不要开始提问；最后一行提示用户回来后说“开始复习”或“开始学习”。

## 3 新学章节

1. 告诉用户本章原文位置，按 `mode` 说明学法：
   - 弱项：先读带示例和推导的小节，再合书作答。
   - 一般：精读后合书，口述三个要点。
   - 强项：快速浏览，直接闭卷做题。
2. 用户读完后，让他合书口述本章要点，你对照自测清单指出漏掉的。
3. 运行 `coach.py learned <章节ID>`，本章题目进入复习队列，当天到期；接着按 [drill.md](drill.md) 练一轮。
4. 章节标为“待补”（没有题目）时：读完口述要点即可，仍然运行 `learned`。

## 4 复习和手撕

复习按 [drill.md](drill.md)。手撕题让用户在自己的编辑器里写，写完贴代码，你对照题目里的要点和易错点检查，再按 0/1/2 打分并 `record`（手撕题的题号以 `code-` 开头）。

## 5 收尾

今天的事做完后运行 `coach.py stats`，用一两句话总结：今天练了多少题、几道达标、明天要重点补什么。
