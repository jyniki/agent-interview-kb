# 真实面试复盘

用户刚面完，趁记忆清楚把被问到的题记下来。这些题优先级最高。

## 流程

1. 让用户按顺序回忆被问到的问题和追问，以及自己当时怎么答的。一次问一个：“第一个问题是什么？”“追问了什么？”“你当时怎么答的？”
2. 对每个问题，在知识库里找对应的题：可以根据关键词浏览相关章节的 `questions.md`，或用 `show <题号>` 确认。
3. 找到对应题：

   ```bash
   python3 scripts/coach.py debrief --qid <题号> --score <当时答得怎样 0/1/2> --company "公司或轮次" --note "被追问了xxx"
   ```

4. 知识库里没有：

   ```bash
   python3 scripts/coach.py debrief --text "题目原文" --score 0 --company "公司或轮次"
   ```

   脚本会生成 `custom-001` 这样的题号。这类题没有标准答案，复习时由你和用户一起整理要点；如果这道题有通用价值，可以建议用户把它贡献到知识库（见仓库的 CONTRIBUTING.md，记得去掉公司和个人信息）。

5. 所有题记完后，挑一两道当时答得最差的，立刻按 [drill.md](drill.md) 练一遍。

## 注意

- 公司名、面试官等信息只存在本地 `$AIKB_HOME`，不要写进仓库。
- 不要根据一次面试推断“这家公司一定会问什么”，只把被问到的题加进复习。
