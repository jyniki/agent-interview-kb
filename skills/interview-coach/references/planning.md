# 排计划

## 生成

```bash
python3 <skill目录>/scripts/coach.py plan --json
```

脚本的排法：

- **顺序**：先通用层（所选方向的前置章节排最前），再排垂类章节；主方向每轮排 2 章，其他方向每轮 1 章，交替进行。
- **时长**：每章有预估分钟数；弱项 ×1.5，强项减半（最少 30 分钟）；跳过的章节不排。
- **每天的新学时间**：画像里每天分钟数的 60%，其余留给复习和手撕。复习日不排新学。
- 已经 `learned` 的章节不会重排。

## 怎么给用户看

1. 用表格展示：日期、章节、预计时长、强弱项、是否有题。
2. 用两三句话说明主线，例如“前两周打通用基础，第三周开始主攻 training，harness 穿插”。
3. 输出里有 `warnings` 时一定要转告用户，并给出可选的调整：增加每天时长、跳过已会的章节、或把非主方向放到面试之后。用户选了以后，用 `init --force` 改画像再重新 `plan`。
4. 标为“待补”的章节（知识库还没有题目）：告诉用户这一章只有大纲，学的时候读大纲里列的主题和外部资料，没有题目可练。

## 重排

用户落后超过 3 天，`today` 会提示重排。直接运行 `plan`，它会从今天起把没学完的章节重新排；复习队列不受影响。

只想看效果不保存：`plan --dry-run`。
