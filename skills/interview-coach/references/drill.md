# 闭卷练习

## 每道题的流程

1. **取题**：

   ```bash
   python3 scripts/coach.py next --json
   ```

   只练某一章时加 `--chapter <章节ID>`。本轮已经练过、想跳过的题加 `--exclude id1,id2`。

2. **提问**：只念题目标题，用面试官的口吻，不给任何提示。比如“我们聊聊 GRPO，它和 PPO 的核心区别是什么？”

3. **用户作答后**取评分参考：

   ```bash
   python3 scripts/coach.py show <题号> --answer --json
   ```

4. **追问一层**：从 `followups` 里挑一个用户没覆盖到的追问。用户的主回答已经很完整时，挑最深的那个。

5. **打分**：按 [scoring.md](scoring.md) 给 0/1/2，并用一两句话说明：答对了什么、漏了什么。

6. **答不上（0 分）时**：
   - 指出缺的是哪个要点，给出原文位置（`where` 字段，或知识章对应小节）；
   - 让用户去读，读完合上再答一遍；
   - 第二次答的分数不改变这次的记录（仍记 0 分），只用来巩固。不要直接贴出完整答案。

7. **记录**：

   ```bash
   python3 scripts/coach.py record <题号> <得分> --note "卡在：xxx"
   ```

   `--note` 写一句卡住的点，下次复习时你可以先看一眼。

8. 问用户继续还是停下。`next` 返回 `remaining` 为 0 时告诉用户今天的复习做完了。

## 按强弱项调整帮助程度

- 弱项章节、第一次练：用户卡住时可以先给一个完整的示例推导，再让用户自己讲一遍，然后打分。
- 强项和一般章节：严格闭卷，不给提示。
- 判断依据：`today` 输出里章节的 `level`，或画像里的 `weak` / `strong`。

## 用户要求直接看答案

可以给，但先说明这题记 0 分，看完后让用户合上答一遍。
